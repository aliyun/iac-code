# 基本操作

以下の手順はデスクトップと Web に共通です。両者は同じ会話画面を使用します。

## 新しい会話を開始する

1. デスクトップを開くか、対話端末で `iac-code` を実行して Web を開きます。

2. サイドバーの**新しいチャット**をクリックし、入力欄の下でプロジェクトのディレクトリを選択します。既存ファイルの参照や生成テンプレートの保存に使用されます。

3. 最初の送信前に**通常モード**または**パイプラインモード**を選びます。パイプラインの場合は具体的なフローも選択します。

4. 依頼を入力して送信します。会話はサイドバーのプロジェクト配下に表示され、そこで続行できます。

## 既存ファイルや画像を参照する

1. ファイルがあるプロジェクトの会話を開きます。

2. 入力欄で `@` とファイル名の一部を入力し、候補を選択します。ファイル参照が入力欄付近に表示されます。画像は添付ボタンから選びます。

3. 「参照した ROS テンプレートを確認し、必要なパラメーターを説明してください」などの依頼を追加し、参照先を確認して送信します。

## 会話のモデルと思考を選ぶ

1. 先に[モデル設定](../configuration/llm-providers.md)の手順でプロバイダーを登録します。

2. 会話に戻り、入力欄の下のモデル選択からプロバイダーとモデルを選びます。

3. 対応するモデルでは推論の強度を選べます。**思考**スイッチは現在の会話の思考を切り替えます。

4. 表示されたモデルを確認して次の依頼を送信します。利用可能な思考設定はモデルにより異なります。

## ツールの承認に回答する

1. 送信前に入力欄の権限コントロールを開き、権限モードを選びます。

2. 承認カードが表示されたら、ツール名と実行内容を読み、対象ファイルやクラウド API を確認します。

3. カードで許可または拒否します。許可すると保留中の操作が続行され、拒否すると結果がアシスタントへ返されます。質問カードには別途必要な情報を回答します。

## 指示とメモリーを管理する

1. **設定 → メモリー**を開き、上部で対象プロジェクトを選びます。

2. **プロジェクトメモリー**にそのプロジェクト専用の指示を入力し、同じ欄の**保存**をクリックします。

3. **ユーザーメモリー**にプロジェクト共通の好みを入力し、その欄の**保存**をクリックします。各編集後に保存の確認を待ちます。

4. 作業中の有用な事実を記録させる場合は、**自動メモリー → 自動記録**を切り替えます。変更は自動保存されます。

5. **メモリーライブラリ**で記録を検索して内容を確認します。不要な項目は削除ボタンをクリックし、確認して削除します。

## 言語と外観を変更する

1. **設定 → 一般**を開きます。

2. **言語**を選択します。自動保存後、選んだ言語でページが再読み込みされます。

3. **配色テーマ**でテーマをクリックします。表示が更新され、選択が自動保存されます。

## 任意の入力ショートカット

既存の通常会話で `/` を入力すると、少数のショートカットが表示されます。

| ショートカット | 用途 |
|---|---|
| `/status` | 現在のセッション状態を表示します。 |
| `/compact` | 会話を要約してコンテキストを削減します。 |
| `/mcp` | MCP サーバーの状態を表示します。接続設定は**プラグイン → MCP**で管理します。 |

Pipeline では `/compact` が非表示になり、新しい会話の下書きにはこれらの項目は表示されません。候補からスキルを選んで依頼を追加し、送信することもできます。詳細は[スキル](./skills.md)を参照してください。
