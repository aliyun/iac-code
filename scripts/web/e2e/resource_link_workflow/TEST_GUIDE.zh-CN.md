# 资源链接测试指南

## 单位与四维度

每个 R 编号是一种资源，不再按旧批次组织。一次资源任务包含下面四项及各自 iframe / 直接打开两个分支；依赖资源必须另有编号或明确为已有只读前置条件。

| 维度 | 来源要求 | 创建与清理 |
| --- | --- | --- |
| ROS | 正式 Web 操作 ROS 创建栈，真实资源状态/PhysicalResourceId | 删除本任务栈，验证资源消失；非本任务已有栈不能删除 |
| Terraform | **ROS 服务托管 Terraform 栈**，不是本机 Terraform CLI | 由 ROS 创建/删除托管栈，核对输出和底层资源消失 |
| 创建 API | Web 产品执行批准的创建 API，返回真实资源引用 | 记录实际 API 输出、ID、账号、地域、任务所有权；完成后批准的删除请求并只读核实消失 |
| 查询 API | test-guima 的真实只读响应与产品结构化引用 | 优先复用有效原始来源；不删除已有资源 |

缺少某维度，必须保留该行，记官方不适用依据；支持未知不能派发。不支持 iframe 是浏览器政策/官方能力状态，不是产品实现 FAIL；直接打开仍须独立验证。

冻结定向导航复测是明确的执行范围例外：只执行失败 QUERY / ROS 场景，未选维度原行和状态全部
保留。ROS 可只读已有栈资源的真实 ROS 响应，不重复创建或删除已有对象；仍须新会话实际签名
来源、点击和独立截图验收。这个模式只证明导航，不证明 ROS 创建链，不自动扩展其他维度。

## 阶段与不可混淆的状态

准备 → ready → 单 GLM 执行 → 提交原始结果 → 精确回合终态 → Sol 逐图验收 → 清理确认 → complete。
FAIL / 产品缺陷 / 执行遗漏进入修复重试，只补缺项；没有截图、账号/地域/来源绑定或稳定落点，不能记 PASS。

- 有资源但生成不了链接：先确认真实来源与产品输出，区分产品提取/渲染缺陷与 GLM 未执行；产品缺陷由 Sol 修代码和离线测试后重测。
- 来源/计划输入缺口：修正规入口，不能借其他来源 PASS。
- 有界核查无资源：保存实际地域、API、分页、时间和失败盲区，不推断全云不存在。
- 创建结果未经确认：保留资源所有权/租约，不盲目重复创建。
- 落点仍加载：不能自动通过；截图说明“未稳定”，查明是产品、登录、网络还是过早截图。

## 证据

GLM 自建正式 UI 会话，以批准的自然语言请求获得引用；已知资源 ID、ResourceType、控制台 URL 不能出现在自然语言请求中。查询请求只读；创建/删除仅用 Sol/OPS 批准的固定文本，不能即兴扩大操作。

每个分支保存原始 PNG、机器 JSON、完整活动 session key、slot origin/target、精确 source SHA、账号/地域和最后 URL。API 原始响应与 Web 新会话 messages/references 不得伪造。runner/browser 的机器输出记录实际点击，不自动判断 PASS。

Sol 必须调用 inspect 实际查看每张原图。通过要同时确认登录、精确资源身份、稳定渲染。程序检查 PNG SHA 与已查看记录；截图被修改后回执拒绝。视觉结论和原始 API 证据共同验收，不能以 HTTP200 或文字总结代替截图。

## 清理与费用

免费或按量可删除资源可以作为候选；开始前核对账单影响、最短计费、依赖和删除语义。预算以分计，所有重试累计预留，不能用拆任务绕过总额。
必须登记本任务所有创建物，包括失败栈和旁路依赖；delete accepted 不等于资源已不存在。清理证据必须是实际只读确认；未清理不得释放槽或 close。暂时无法清理交 OPS，禁止为了推进修改“已删除”状态。

复用现有测试账号，不强制另建 RAM 身份。程序在实际 API 传输前校验账号/签名凭据、完整会话、精确参数与地域、次数和阶段，管理员或产品全权限设置也不能绕过。每条创建只有一次调用机会，删除 ID 绑定其真实响应；未知结果保留意图，重启不重建。ROS/ROS 托管 Terraform 使用预审内联模板的 ROS API，不允许任意 Shell/模板 URL。OPS 的计划审查是操作授权，不是假称云 IAM 已收窄。

## 历史结果

历史入口、别名、来源、两个点击模式分别保留。旧 PASS 不重放；旧 Terraform 链接 PASS 不证明新的 ROS 托管 Terraform 创建链已完成。截图判断矛盾时记录待核，不静默改 PASS。
