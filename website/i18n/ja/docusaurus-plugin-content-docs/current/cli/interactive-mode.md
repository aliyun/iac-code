# 従来のターミナル起動

TUI は、端末内で会話やツール操作を行う従来のインターフェースです。本ページは既存のターミナル作業を続ける方向けの説明です。

:::note

TUI の更新と保守は終了しています。新しい画面機能は [Web](../web-app.md) と[デスクトップ](../desktop-app.md)が対象であり、端末画面で同じ操作や表示が利用できるとは限りません。

:::

## 起動と基本操作

1. [Python パッケージ](../getting-started/installation.md)をインストールし、[モデルプロバイダー](../configuration/llm-providers.md)を設定します。クラウド操作には[Alibaba Cloud 認証情報](../configuration/alibaba-cloud-credentials.md)も設定します。保存済みの設定は TUI でも利用できます。

2. 対話端末を開き、プロジェクトのディレクトリへ移動して起動します。

   ```bash
   cd /path/to/project
   iac-code tui
   ```

3. 保守終了の案内と入力欄が表示されたら、依頼を入力して送信します。返信やツールの実行状況は端末に表示されます。質問や承認が必要な場合は端末の案内に回答します。

4. `/help` でインストール済みバージョンのコマンドを確認し、`/status` で現在のセッションを確認します。終了には `/exit` を使います。

TUI には対話端末が必要です。端末のないスクリプトや CI には [headless 自動化](../automation/non-interactive-mode.md)を使用します。サブコマンドなしの `iac-code` は既定で Web を開きます。

## 既存の端末会話を続ける

会話のプロジェクトディレクトリから実行します。セッション ID または一意の名前で指定する場合：

```bash
iac-code tui --resume <session-id-or-name>
```

現在のプロジェクトの最新セッションを続ける場合：

```bash
iac-code tui --continue
```

`--resume` と `--continue` は併用できません。起動オプションは `iac-code tui --help` で確認してください。

## Web またはデスクトップへ移る

1. `iac-code web` を実行するか、インストール済みのデスクトップを開き、同じプロジェクトディレクトリを選びます。

2. 同じ OS ユーザーと `IAC_CODE_CONFIG_DIR` を使用すると、保存済みのモデル設定、クラウド認証情報、指示メモリーを再利用できます。以後は設定画面で管理します。手順は[基本操作](./commands.md)を参照してください。

3. 新しい会話を開始します。以前の端末会話を確認するには、**設定 → 一般 → 外部セッションの表示**で該当する読み取り専用の表示を有効にします。保存先が共通でも端末会話を Web/デスクトップで編集できるわけではありません。詳しくは[セッション](./sessions.md)を参照してください。
