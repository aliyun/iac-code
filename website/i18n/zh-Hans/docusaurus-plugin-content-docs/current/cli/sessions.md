# 会话管理

Web、桌面版和 headless 共用会话存储。对话会自动保存在运行时配置目录下。

## Web 与桌面版

### 继续历史对话

1. 在侧栏找到对应项目，单击需要继续的对话；也可以通过**搜索**按标题查找。

2. 查看已保存的消息和生成文件。

3. 在输入框补充后续需求并发送；需要独立上下文的新任务时，使用**新对话**。

### 重命名或置顶对话

1. 打开对话，单击对话的 **…** 菜单。

2. 选择**重命名对话**，填写新标题并单击**保存**，侧栏会显示更新后的标题。

3. 需要方便后续查找时，在同一菜单选择**置顶对话**；之后可通过取消置顶操作移除。

### 归档与恢复对话

1. 在对话的 **…** 菜单选择**归档对话**，该对话会从活动侧栏列表移出。

2. 需要恢复时，打开**设置 → 已归档对话**，通过搜索和项目筛选找到对话。

3. 单击该对话旁的**取消归档**，返回侧栏打开对话即可继续。

:::note

CLI、A2A 或 ACP 创建的会话默认隐藏。需要查看时，打开**设置 → 常规 → 外来会话可见性**，启用相应的只读显示选项。共用会话存储不代表这些会话可以在 Web/桌面版中继续编辑。

:::

## Headless 续聊

从会话所属的项目目录运行。使用 `--resume` 指定会话，或使用 `--continue` 继续该项目的最近一次会话；短参数分别为 `-r` 和 `-c`，两者不能同时使用。

```bash
iac-code --resume deploy-prod --prompt "生成一个 VPC 模板"
iac-code --continue --prompt "生成一个 VPC 模板"
```

## 其他项目

在 Web 或桌面版中，从侧栏对应项目下打开会话。headless 运行时，先切换到该项目目录：

```bash
cd /path/to/project
iac-code --resume <session-id> --prompt "生成一个 VPC 模板"
```

## 中断后继续

重新打开已保存的会话，查看历史并继续工作。恢复时会处理未完成的工具调用。Pipeline 的进度与待处理决策按 [Pipeline 恢复流程](../automation/pipeline-mode.md)恢复；单条 `--prompt` 调用不执行 Pipeline。
