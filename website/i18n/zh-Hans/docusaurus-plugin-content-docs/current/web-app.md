# Web 应用

IaC Code 内置了一个本地 Web 应用，它运行与终端完全相同的智能体引擎，只是把界面从 REPL 换成了浏览器。当你更习惯图形化聊天界面、想并排管理多个对话，或希望以更丰富的布局观察流水线进度与工具活动时，它会很有用。

Web 应用读写与 CLI 相同的会话存储，因此在一端开始的对话可以在另一端恢复。

## 启动 Web 应用

在终端中启动服务：

```bash
iac-code web
```

默认绑定到 `127.0.0.1:8766`，并在 `http://127.0.0.1:8766` 打开你的默认浏览器。

| 选项 | 默认值 | 说明 |
|---|---|---|
| `--host` | `127.0.0.1` | HTTP 服务主机。仅接受回环地址。 |
| `--port` | `8766` | HTTP 服务端口。 |
| `--open` / `--no-open` | `--open` | 启动时打开浏览器。使用 `--no-open` 可禁用。 |

```bash
iac-code web --port 9000 --no-open
```

### 安全性

Web 服务仅绑定回环接口（`127.0.0.1`、`localhost` 或 `::1`）。它面向本机使用，会拒绝公网绑定地址。请勿将其直接暴露到网络中；若需要远程访问，请置于你自己的带鉴权的代理之后。

## 界面概览

### 会话侧栏

侧栏列出所选项目下的对话。你可以在这里：

- 开始**新对话**，或用项目选择器切换项目。
- **搜索**对话，或打开命令面板运行命令。
- **置顶**、**重命名**或**归档**对话，并浏览已归档的对话。

由于会话与 CLI 共享，你用 `iac-code --resume` 恢复的对话也会出现在这里。会话存储的工作方式详见[会话管理](./cli/sessions.md)。

### 输入区（Composer）

输入区是你键入需求的地方。它提供了 CLI 通过斜杠命令与命令行参数所暴露的同一批控制项：

- 为当前会话选择**模型与提供商**。
- **思考**开关，为支持的模型启用或关闭扩展推理。
- **权限模式**控制项，决定工具操作的审批方式。
- 面向多模态模型的**图片附件**。
- **斜杠命令**（以 `/` 键入）与 **`@` 文件引用**，用于指向工作区中的文件。

### 普通聊天与流水线模式

会话可以作为普通聊天运行，也可以在**流水线**模式下运行。普通聊天会内联流式显示助手的回复、工具调用与结果。流水线模式则额外提供一个工作区，在流水线运行过程中展示步骤时间线、诊断、图示、部署进度、清理与交接详情。流水线的作用详见[流水线模式](./automation/pipeline-mode.md)。

### 工具与审批

工具调用会在对话记录中以卡片形式呈现。当某个工具需要你审批时，审批请求会内联出现；输入区中设置的权限模式决定何时向你征询。

### 设置

设置区汇集了 CLI 所管理的同一批配置：

- 阿里云的**云凭据**（见[阿里云凭据](./configuration/alibaba-cloud-credentials.md)）。
- **模型**与提供商配置（见 [LLM 提供商](./configuration/llm-providers.md)）。
- **MCP 插件**（见 [MCP 集成](./mcp/overview.md)）。
- **记忆**的查看与管理。

### 界面语言

Web 应用提供七种语言 —— English、简体中文、日本語、Français、Deutsch、Español 与 Português —— 可在设置中选择。你的选择会被保存，供后续会话使用。

## 与 CLI 的关系

Web 应用是另一种前端，而非独立产品。它使用与终端相同的提供商、凭据、技能、工具与会话存储。用 CLI 的 `/auth` 或 Web 应用的设置配置一次提供商与凭据，两个界面便共享同一份配置。
