# 常用操作

以下步骤同时适用于桌面版和 Web，两者使用同一套对话界面。

## 新建对话并发送需求

1. 打开桌面应用，或在交互终端运行 `iac-code` 打开 Web。

2. 单击侧栏的**新对话**，在输入框下方的项目控件中选择目录。该目录用于读取已有文件和保存生成的模板。

3. 首条消息发送前，选择**普通模式**或**流水线模式**；选择流水线模式时，再选择具体流水线。

4. 输入需求并发送。侧栏会在对应项目下显示这条对话，后续可在同一对话中继续提问。

## 引用已有文件或添加图片

1. 打开文件所在项目的对话。

2. 在输入框键入 `@`，输入部分工作区文件名，选中候选文件；输入区会显示文件引用。需要补充图片时，使用附件控件选择图片。

3. 补充操作要求，例如“检查引用的 ROS 模板，说明需要填写哪些参数”，确认引用项后发送。

## 选择会话模型与思考方式

1. 先按[配置模型](../configuration/llm-providers.md)中的步骤完成提供商设置。

2. 返回对话，单击输入框下方的模型控件，选择可用的提供商和模型。

3. 如果模型支持，选择思考强度；通过**思考**开关控制当前会话是否启用思考。

4. 确认输入框下方显示的模型后，再发送下一条需求。可选的思考设置取决于模型能力。

## 处理工具权限确认

1. 发送需求前，单击输入框中的权限控件，选择所需的权限模式。

2. 对话中出现权限卡片时，查看工具名称及待执行操作，核对目标文件或云 API。

3. 通过卡片批准或拒绝。批准后，待执行操作继续；拒绝后，助手会收到拒绝结果。若另有提问卡片，按卡片补充所需信息。

## 编辑指令和管理记忆

1. 打开**设置 → 记忆**，在顶部选择需要管理的项目。

2. 在**项目记忆**区域填写仅适用于该项目的指令，单击该区域的**保存**。

3. 在**用户记忆**区域填写跨项目生效的偏好，单击对应的**保存**；每次编辑后确认已保存提示。

4. 需要助手在工作过程中记录有用事实时，打开或关闭**自动记忆 → 自动记录**开关。开关变更自动保存。

5. 在**记忆库**中搜索并查看已记录的内容；需要移除过时条目时，单击对应的删除控件并确认。

## 切换语言和外观

1. 打开**设置 → 常规**。

2. 在**界面语言**中选择界面语言。选择会自动保存，页面随后按所选语言重新加载。

3. 在**配色方案**中单击所需主题，界面会更新并自动保存选择。

## 可选的输入快捷项

在已有的普通会话中输入 `/`，可以看到少量快捷项：

| 快捷项 | 用途 |
|---|---|
| `/status` | 查看当前会话状态。 |
| `/compact` | 总结压缩对话，降低上下文占用。 |
| `/mcp` | 查看 MCP 服务器状态；连接配置在**插件 → MCP**中管理。 |

Pipeline 会话会隐藏 `/compact`；新对话草稿中不显示上述会话快捷项。技能也会出现在候选菜单中，选中后补充需求并发送即可。详见[技能](./skills.md)。
