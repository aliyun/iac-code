# セッション

Web、デスクトップ、headless は同じセッションストアを使用します。会話はランタイム設定ディレクトリに自動保存されます。

## Web とデスクトップ

### 過去の会話を続ける

1. サイドバーのプロジェクト配下で会話を開くか、**検索**でタイトルを探します。

2. 保存済みのメッセージとファイルを確認します。

3. 続きの依頼を入力して送信します。独立した作業は**新しいチャット**で始めます。

### 会話の名前を変更・固定する

1. 会話を開き、**…** メニューをクリックします。

2. **会話の名前を変更**を選択し、タイトルを入力して**保存**します。サイドバーのタイトルが更新されます。

3. 見つけやすくするには、同じメニューで会話を固定します。後で同じメニューから固定を解除できます。

### 会話をアーカイブ・復元する

1. **…** メニューで**会話をアーカイブ**を選びます。会話が通常の一覧から外れます。

2. **設定 → アーカイブ済みの会話**を開き、検索とプロジェクト絞り込みで探します。

3. 会話の**アーカイブを解除**をクリックし、サイドバーから開いて続行します。

:::note

CLI、A2A、ACP で作られた会話は既定で非表示です。確認するには**設定 → 一般 → 外部セッションの表示**で該当する読み取り専用の表示を有効にします。保存先が共通でも、Web/デスクトップで編集できるわけではありません。

:::

## Headless での続行

セッションのプロジェクトディレクトリで実行します。`--resume` でセッションを指定するか、`--continue` でそのプロジェクトの最新セッションを続けます。短縮形は `-r` と `-c` で、併用できません。

```bash
iac-code --resume deploy-prod --prompt "VPC テンプレートを生成する"
iac-code --continue --prompt "VPC テンプレートを生成する"
```

## 別のプロジェクト

Web またはデスクトップではサイドバーの対象プロジェクトから会話を開きます。headless では先にそのディレクトリへ移動します。

```bash
cd /path/to/project
iac-code --resume <session-id> --prompt "VPC テンプレートを生成する"
```

## 中断した会話

保存済みの会話を開き、履歴を確認して続行します。復元時に未完了のツール呼び出しが処理されます。Pipeline の進捗と保留中の判断は [Pipeline の復元手順](../automation/pipeline-mode.md)に従います。単一の `--prompt` 実行では Pipeline は実行されません。
