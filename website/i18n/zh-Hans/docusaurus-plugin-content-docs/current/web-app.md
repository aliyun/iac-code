# Web 应用

在终端运行 `iac-code`，即可启动本地 Web 应用并打开浏览器。首次使用时，在设置中配置 LLM 提供商和阿里云凭证。

Web 应用读写与 CLI 相同的会话存储，因此在一端开始的对话可以在另一端恢复。

## 安装

默认安装已包含 Web 和 HTTP 运行时依赖。`[http]` 扩展保留为兼容别名，无需单独安装。在仓库检出环境中运行 `uv sync` 即可。

```bash
pip install iac-code
```

## 启动 Web 应用

在终端中启动服务：

```bash
iac-code web
```

默认绑定到 `127.0.0.1:8766`，并在 `http://127.0.0.1:8766` 打开你的默认浏览器。

| 选项 | 默认值 | 说明 |
|---|---|---|
| `--host` | `127.0.0.1` | HTTP 服务主机。本地模式接受回环地址；其他 IP 地址需要 `--access-token-file`。 |
| `--port` | `8766` | HTTP 服务端口。 |
| `--open` / `--no-open` | `--open` | 启动时打开浏览器。使用 `--no-open` 可禁用。 |
| `--debug`, `-d` | `false` | 为本次运行启用服务端调试日志。 |
| `--access-token-file <path>` | — | 用于显式远程访问的令牌文件，API 请求使用加密传输。 |

```bash
iac-code web --port 9000 --no-open
```

### 安全性

未指定 `--access-token-file` 时，服务仅接受回环地址（`127.0.0.1`、`localhost` 或 `::1`），并校验本地请求。显式令牌模式也接受其他 IP 地址，API 请求通过加密令牌传输保护。

## 界面概览

### 会话侧栏

侧栏列出所选项目下的对话。你可以在这里：

- 开始**新对话**，或用项目选择器切换项目。
- **搜索**对话，或打开命令面板运行命令。
- **置顶**、**重命名**或**归档**对话，并浏览已归档的对话。

由于会话与 CLI 共享，你用 `iac-code tui --resume` 恢复的对话也会出现在这里。会话存储的工作方式详见[会话管理](./cli/sessions.md)。

### 输入区（Composer）

输入区是你键入需求的地方。它提供了 CLI 通过斜杠命令与命令行参数所暴露的同一批控制项：

- 为当前会话选择**模型与提供商**。
- **思考**开关，为支持的模型启用或关闭扩展推理。
- **权限模式**控制项，决定工具操作的审批方式。
- 面向多模态模型的**图片附件**。
- **斜杠命令**（以 `/` 键入）与 **`@` 文件引用**，用于指向工作区中的文件。

### 普通聊天与流水线模式

新建会话时选择模式；使用流水线模式时，再选择具体流水线。同一个应用中的会话可以使用不同模式，无需重启服务。

会话可以作为普通聊天运行，也可以在**流水线**模式下运行。普通聊天会内联流式显示助手的回复、工具调用与结果。流水线模式则额外提供一个工作区，在流水线运行过程中展示步骤时间线、诊断、图示、部署进度、清理与交接详情。流水线的作用详见[流水线模式](./automation/pipeline-mode.md)。

[`selling_solution_first` 流水线](./automation/solution-first-pipeline.md)在这个工作区中提供三阶段购买流程：比较候选架构、实现选中的方案，并在确认后部署。工具审批会以国际化权限卡的形式显示在发起请求的步骤下；恢复会话时，尚未处理的审批也会回到同一步骤。

### 工具与审批

工具调用会在对话记录中以卡片形式呈现。当某个工具需要你审批时，审批请求会内联出现；输入区中设置的权限模式决定何时向你征询。

### 设置

设置区汇集了 CLI 所管理的同一批配置：

- 阿里云的**云凭据**（见[阿里云凭据](./configuration/alibaba-cloud-credentials.md)）。
- **模型**与提供商配置（见 [LLM 提供商](./configuration/llm-providers.md)）。
- **MCP 插件**（见 [MCP 集成](./mcp/overview.md)）。
- **记忆**的查看与管理。

### 界面语言

Web 应用提供七种语言 —— English、简体中文、日本語、Français、Deutsch、Español 与 Português —— 可在设置中选择。你的选择会被保存，供后续会话使用。

## 与 CLI 的关系

Web、桌面版和 headless 共用提供商、凭证、技能、工具及会话存储。在设置中配置一次模型和云访问后，就能在这些入口间复用。
